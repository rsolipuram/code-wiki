Getting Started

Get your codebase wiki up and running in under 15 minutes. No installation required — Code Wiki is fully hosted. Just connect your repository and we handle the rest.

Onboarding Steps

Follow these five steps to go from signup to a fully-navigable wiki for your codebase.

1

Create Your Account

Sign up at login.html using one of the supported OAuth providers. No password required — we use your existing identity from your code hosting platform.

🐙
Continue with GitHub
Authorizes read access to your repositories and profile
🦊
Continue with GitLab
Works with both gitlab.com and self-hosted GitLab instances
🪣
Continue with Bitbucket
Supports Bitbucket Cloud and Bitbucket Data Center
Privacy note

Code Wiki requests read-only repository access. We never push code or modify your repository in any way.

2

Connect Your Repository

After signing in, go to Add Repository and paste your repository URL. Both public and private repositories are supported.

https://github.com/your-org/your-repo

You can also configure optional analysis settings with a codewiki.yaml file at your repo root:

analysis:
  languages: [python, typescript, go]
  exclude:
    - node_modules
    - dist
    - migrations
  module_threshold: 0.6

wiki:
  generate_diagrams: true
  include_private_functions: false
3

Wait for Analysis

Once submitted, Code Wiki clones your repository and runs the full analysis pipeline. You can track real-time progress at progress.html.

📂
Repository cloned
Shallow clone of the default branch (typically 10–30 seconds)
🔍
Code parsed
Language-specific AST parsing extracts functions, classes, and signatures
🧠
Modules detected & wiki generated
AI groups related code into modules and writes structured documentation
Estimated time

Most repositories complete in 5–10 minutes. Large monorepos (>100k lines) may take up to 30 minutes. You will receive an email when analysis is complete.

4

Explore Your Wiki

When analysis finishes you will land on your repository's wiki home page. From there you can:

  • Browse auto-generated module pages with file trees, key components, and dependency tables
  • Use the search bar to locate any function, class, or concept by name
  • Ask the AI chat assistant natural-language questions about your codebase
  • View auto-generated architecture diagrams and call graphs
5

Set Up Sync Webhooks

Code Wiki automatically installs a webhook on your repository during setup. Whenever you push a commit, the affected modules are re-analyzed and documentation is updated within minutes — no manual action needed.

To trigger a manual full re-sync at any time, call the sync API endpoint or click Sync Now from the repository overview page:

# Trigger a manual sync via the REST API
curl -X POST https://api.codewiki.io/v1/repos/{repo_id}/sync \
  -H "Authorization: Bearer YOUR_API_TOKEN"
Webhook payload

Code Wiki listens for push and pull_request events. Only changed files are re-analyzed, so incremental syncs are typically fast (under 60 seconds for most commits).

Configuration Reference

All settings in codewiki.yaml are optional. Code Wiki applies sensible defaults when the file is absent.

Language Support

Specify which languages to parse. Unrecognised files are skipped automatically.

analysis:
  languages:
    - typescript
    - javascript
    - python
    - java
    - go
    - rust

AI Assistant Context

Tune how much source context the AI chat assistant loads per query:

ai_assistant:
  max_context_files: 12
  include_code_snippets: true
  prefer_recent_commits: true
