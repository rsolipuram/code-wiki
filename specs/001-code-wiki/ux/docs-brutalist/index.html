Core Concepts / Repository Analysis

REPOSITORY
ANALYSIS

AI
Code Wiki Team
Created Feb 15, 2026 · Updated Feb 15, 2026

Code Wiki automatically analyzes repositories to generate comprehensive, structured documentation. The analysis engine examines your codebase structure, identifies modules and components, and creates a navigable knowledge graph of your entire project.

KEY INSIGHT: Repository analysis runs automatically on the first import and whenever you push new commits. Documentation stays synchronized with your code without manual intervention.

HOW IT WORKS

The repository analysis process consists of several sophisticated stages that work together to understand your codebase:

CODE PARSING

Code Wiki uses language-specific parsers to extract semantic information from your source files. For each supported language, we leverage the most accurate parsing strategy:

  • TypeScript/JavaScript: TypeScript Compiler API for 95%+ accuracy in type inference
  • Python: Jedi static analysis for imports, classes, and function signatures
  • Java: JavaParser for AST-based analysis
  • Go: go/parser for native Go AST parsing
{
  "module": "auth/login.ts",
  "exports": [{
    "name": "authenticateUser",
    "type": "function"
  }]
}

MODULE DETECTION

After parsing individual files, Code Wiki groups related code into logical modules based on directory structure, import relationships, and shared dependencies.

CONFIDENCE SCORING

Each detected module receives a confidence score (0.0 to 1.0) based on how clearly defined its boundaries are. Modules with scores below 0.6 are flagged for manual review.

RELATIONSHIP MAPPING

Code Wiki builds a comprehensive graph of relationships between code entities including direct dependencies, data flow, and architectural layers.

PERFORMANCE

Analysis time scales with repository size, but Code Wiki is optimized for large codebases:

  • Small repos (< 10k lines): 30-60 seconds
  • Medium repos (10k-100k lines): 5-10 minutes
  • Large repos (100k+ lines): 10-30 minutes

CONFIGURATION

Customize repository analysis with a codewiki.yaml file:

analysis:
  languages: [typescript, python, go]
  exclude: [node_modules, dist]
  module_threshold: 0.6
